# ML

В папку постепенно будут добавляться ноутбуки по следующим темам классического ML:

1. разведочный анализ и линейная регрессия
2. градиентный спуск
3. регуляризация + кросс-валидация + кодирование категориальных признаков и логистическая регрессия
4. SVM (метод опорных векторов) + многоклассовая классификация
5. нелинейные методы классификации (knn)
6. деревья решений
7. ансамблевые методы
8. градиентный бустинг
9. кластеризация
10. pca (понижение размерности)
