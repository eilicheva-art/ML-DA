# ML

В папку постепенно будут добавляться ноутбуки по следующим темам классического ML:

1. Разведочный анализ и линейная регрессия
2. Градиентный спуск
3. Регуляризация
4. Кросс-валидация 
5. Кодирование категориальных признаков
6. Логистическая регрессия
7. SVM (метод опорных векторов)
8. Многоклассовая классификация
9. Нелинейные методы классификации (knn)
10. Деревья решений
11. Ансамблевые методы
12. Градиентный бустинг
13. Кластеризация
14. Pca (понижение размерности)
