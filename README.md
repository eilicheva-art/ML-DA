# ML

Практическое изучение классического машинного обучения на Python.

В репозитории постепенно добавляются ноутбуки по следующим темам:

 - Разведочный анализ и линейная регрессия ✅
 - Градиентный спуск ✅
 - Регуляризация L1/L2 ✅
 - Кросс-валидация
 - Кодирование категориальных признаков
 - Логистическая регрессия ✅
 - SVM (метод опорных векторов)
 - Многоклассовая классификация
 - Нелинейные методы классификации (KNN)
 - Деревья решений
 - Ансамблевые методы
 - Градиентный бустинг
 -  Кластеризация
 - PCA (понижение размерности)
