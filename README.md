# ML

В папку постепенно будут добавляться ноутбуки по следующим темам классического ML:

1. разведочный анализ
2. линейная регрессия
3. градиентный спуск
4. регуляризация + кросс-валидация + кодирование категориальных признаков
5. логистическая регрессия
6. SVM (метод опорных векторов) + многоклассовая классификация
7. нелинейные методы классификации (knn)
8. деревья решений
9. ансамблевые методы
10. градиентный бустинг
11. кластеризация
12. pca (понижение размерности)
